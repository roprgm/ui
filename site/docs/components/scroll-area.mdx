## Anatomy

Each part's `data-slot`, which a theme styles, is beside it.

```tsx
<ScrollArea> // scroll-area
  <div> // scroll-area-viewport
    <div /> // scroll-area-content, around the children
  </div>
  <div> // scroll-area-scrollbar
    <div /> // scroll-area-thumb
  </div>
</ScrollArea>
```
