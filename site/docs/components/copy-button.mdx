## Examples

### Default

Without children, it's an Icon button, so its tooltip reads Copy, then Copied for a moment. With them, it's a Button they label: the same icon turns into a check, and the label reads Copied for a moment.

<Example name="copy-button/demo" />

### Small

`size` takes an Icon button's sizes, such as `icon-sm` beside a command.

<Example name="copy-button/small" />

### With a label

Children make it a Button, which takes a Button's variants and sizes, such as `flat` in a page's header.

<Example name="copy-button/label" />

## Anatomy

Each part's `data-slot`, which a theme styles, is beside it.

```tsx
<CopyButton> // copy-button, with data-copied, data-variant, and data-size
  <svg> // copy-button-icon
    <g /> // copy-button-copy
    <path /> // copy-button-check
  </svg>
  <span> // copy-button-label, with children
    <span /> // copy-button-text, what you pass
    <span /> // copy-button-copied, which takes its place for a moment
  </span>
</CopyButton>
```
