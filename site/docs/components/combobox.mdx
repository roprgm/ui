## Anatomy

Each part's `data-slot`, which a theme styles, is beside it. Combobox renders them all from its props.

```tsx
<Combobox> // combobox
  <Input /> // combobox-input, with data-size
  <Trigger /> // combobox-trigger
</Combobox>
<Portal> // combobox-portal
  <Positioner> // combobox-positioner
    <Popup> // combobox-content, with data-raised
      <Empty /> // combobox-empty
      <List> // combobox-list
        <Item> // combobox-item
          <ItemIndicator /> // combobox-item-indicator
        </Item>
      </List>
    </Popup>
  </Positioner>
</Portal>
```
