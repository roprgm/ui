Each `Toggle` is a label around a hidden radio, so toggles that share a `name` choose one and a form reads the choice. The group holds them a size smaller than a Button, so in a row it takes the Button's height.

## Anatomy

Each part's `data-slot`, which a theme styles, is beside it.

```tsx
<ToggleGroup> // toggle-group, with data-size
  <Toggle> // toggle
    <input /> // toggle-input
  </Toggle>
</ToggleGroup>
```
