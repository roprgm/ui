## Examples

### Default

A table is a card's content, and its head is the card's header: alone in a `Card`, it runs edge to edge, and the card clips its corners. Numbers line up in `tabular-nums`; right-align a numeric column with `text-right` on its head and its cells.

<Example name="table/demo" />

### Selecting rows

A row with `data-selected`, true or false, is one you pick: it lights on hover, and fills when true. Other rows stay still. In a `DragToggle`, with a `name` they share, a drag across the checkboxes flips each one it passes.

<Example name="table/select" />

### Scrolling down

Give the table a height, such as `max-h-80`, and its rows scroll under the head, which stays at the top.

<Example name="table/long" />

### Scrolling sideways

A table never wraps or stacks its columns: in a narrower card, what doesn't fit scrolls, fading at the edges.

<Example name="table/scroll" />

## Anatomy

Each part's `data-slot`, which a theme styles, is beside it. A light line, in `border-light`, runs under each row but the last.

```tsx
<Table> // section, around table
  <TableHeader> // table-header
    <TableRow> // table-row
      <TableHead /> // table-head
    </TableRow>
  </TableHeader>
  <TableBody> // table-body
    <TableRow> // table-row, with data-selected
      <TableCell /> // table-cell
    </TableRow>
  </TableBody>
  <TableFooter /> // table-footer
</Table>
```
