## Anatomy

Each part's `data-slot`, which a theme styles, is beside it.

```tsx
<IconButton /> // icon-button, with data-variant and data-size
<TooltipContent> // tooltip-content, with the label
  <Kbd /> // kbd, the shortcut
</TooltipContent>
```
