## Anatomy

Each part's `data-slot`, which a theme styles, is beside it.

```tsx
<Dialog>
  <DialogTrigger /> // dialog-trigger, or the slot of the element it renders
  <DialogContent> // dialog-content, over a dialog-backdrop
    <Section> // section
      <DialogTitle /> // dialog-title
      <DialogDescription /> // dialog-description
    </Section>
    <Section> // section
      <DialogClose /> // dialog-close, or the slot of the element it renders
    </Section>
  </DialogContent>
</Dialog>
```
