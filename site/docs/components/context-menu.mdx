## Anatomy

Each part's `data-slot`, which a theme styles, is beside it.

```tsx
<ContextMenu>
  <ContextMenuTrigger /> // context-menu-trigger, or the slot of the element it renders
  <ContextMenuContent> // context-menu-content
    <MenuItem /> // menu-item
    <MenuSeparator /> // separator
    <Submenu>
      <SubmenuTrigger /> // submenu-trigger
      <SubmenuContent> // submenu-content
        <MenuItem /> // menu-item
      </SubmenuContent>
    </Submenu>
  </ContextMenuContent>
</ContextMenu>
```
