Its `Section`s stack with a line between each; the first reads as a header and the last as a footer. `SectionAction` holds a header's icon buttons, reaching into its padding so each icon sits 12px in.

For a panel docked in a layout, put `surface-panel` and `sections()` on your own element.

## Anatomy

Each part's `data-slot`, which a theme styles, is beside it.

```tsx
<Card> // card
  <Section> // section
    <SectionAction /> // section-action
  </Section>
</Card>
```
