A theme imports `base.css` and sets again only what it changes. Themes share no helpers, so each one reads on its own.

## What a theme sets

- **Materials on the page**: their fills and edges, as tokens in `@theme`, with the other colors.
- **Materials inside each container**: on its class, every variable it changes, since one a container leaves alone keeps the page's.
- **Edges** are a `box-shadow`, never a `border`, which takes room. A card's inner edge, `--inset-shadow-card`, is drawn on a frame over what it holds.
- **One component's part**: through its public `data-slot`, with colors through the tokens the part reads.

## Example

```css
@import "tailwindcss";
@import "@roprgm/ui/base.css";

/* Materials and colors, on the page. */
@theme {
  --color-panel: var(--color-level-3);
  --color-control: var(--color-level-5);
  --color-field: var(--color-level-0);
  --color-accent: oklch(67% 0.16 252);
  --color-primary-hover: oklch(72% 0.15 252);

  --shadow-card: 0 1px 1px oklch(0% 0 0 / 0.28);
  --inset-shadow-card: inset 0 0 0 1px oklch(100% 0 0 / 0.08);
  --shadow-control: inset 0 1px 0 oklch(95% 0 0 / 0.08);
}

@layer components {
  /* Materials inside a card. */
  .material-card {
    --color-control: var(--color-level-7);
    --color-field: var(--color-level-2);
  }

  /* Materials inside a panel. */
  .material-panel {
    --color-control: var(--color-level-6);
  }

  /* One component, through its slot. */
  [data-slot="button"] {
    --radius-md: 9999px;
  }
}
```
