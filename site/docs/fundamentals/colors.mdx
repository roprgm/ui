Components use only the tokens on this page, with `bg-`, `text-`, or `outline-` and without their `--color-` prefix. A theme picks them from the palette, and sets them again.

```tsx
<p className="text-secondary">Three edits since the import.</p>
```

## Palette

Every fill is a level: black, then from 15% lightness up in even steps of 3.7%. Only themes and containers pick levels; components never do.

<Levels />

## Where you are

The page sets these, and each container sets them again for what sits on it, so the same token reads in a page, a card, and a popup raised over a card. Text takes four opaque steps, so an icon's crossing strokes don't show. The materials' own fills are on [Materials](/fundamentals/materials).
